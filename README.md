# Lapanganin — Booking Lapangan Futsal

Website pemesanan lapangan futsal berbasis web dengan tampilan responsif dan alur booking sederhana.

## Fitur saat ini
- Landing page dan daftar lapangan.
- Filter berdasarkan area dan jenis permukaan lapangan.
- Form booking: nama, WhatsApp, tanggal, jam, dan durasi.
- Estimasi harga otomatis.
- Riwayat booking tersimpan di browser menggunakan localStorage.
- Tampilan responsif untuk desktop dan ponsel.

## Menjalankan
Website menggunakan HTML, CSS, dan JavaScript biasa. Tidak perlu instalasi dependency.

1. Clone repository.
2. Buka folder project.
3. Jalankan `index.html` menggunakan browser atau ekstensi Live Server di VS Code.

## Catatan
Versi ini adalah prototype frontend. Data lapangan masih berupa data contoh dan booking tersimpan di browser perangkat yang digunakan. Login, dashboard admin, database, sinkronisasi jadwal, dan pembayaran belum terhubung.

## Rencana pengembangan
- Supabase Auth untuk akun pelanggan dan admin.
- Database lapangan, jadwal, dan transaksi booking.
- Validasi bentrok jadwal di sisi server/database.
- Dashboard admin untuk mengelola lapangan dan booking.
- Deploy ke Vercel.

## Teknologi
HTML5 · CSS3 · JavaScript · LocalStorage
